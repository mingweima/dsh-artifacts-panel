# 截图与演示素材：拍摄脚本

README 顶部预留了三个图位，文件名固定，放进去即可生效：

- `docs/screenshot-1.png` → `![产物面板](docs/screenshot-1.png)`
- `docs/screenshot-2.png` → `![按任务 / 轮次分组](docs/screenshot-2.png)`
- `docs/screenshot-3.png` → `![主题与字号设置](docs/screenshot-3.png)`

要求：真实界面截图（不要合成、不要占位图、不要示意图）；PNG；建议 2 倍屏导出；截图里出现的项目名、路径、会话标题请先脱敏或换成演示会话；深色主题优先（与图标配色一致）。三张统一同一台机器、同一主题，看起来才像一套。

## 1. `screenshot-1.png` — 面板全貌

- 建议尺寸：1440×900（宽屏）。
- 拍什么：打开一个有真实产物的会话，从会话顶部「产物」页签进入完整面板。
- 画面里要能看清：
  - 工具栏三分区：身份（本会话 / 全部会话 · 轮次 / 任务 / 运行）、筛选（全部 / 文档 / 图片 / 文件、搜索框、筛选▾）、动作（刷新、设置、在右侧栏打开、⋯）。
  - 至少 6–8 张产物卡片，且文档、图片、文件三种类型各至少一张。
  - 卡片上的 ☆ 与 ⋯ 按钮、路径行（确认是中间省略、末尾保留文件名）。
- 这一张是主图，优先保证清楚可读：字号用默认 1.5 倍，不要把窗口压窄。

## 2. `screenshot-2.png` — 按任务 / 轮次分组

- 建议尺寸：1440×900。
- 拍什么（二选一，哪个更能体现「东西多但有序」就拍哪个）：
  - **任务维度**：切到「任务」，展开一个任务组，露出负责人 / 成员徽标与组内产物；有子代理时展示「含子代理 N」与子会话下钻入口。
  - **轮次维度**：右侧栏拉到 ≥720px 宽，让轮次头 + 左回复 / 右资产的两栏布局出现；轮次头带「看改动」「无产物」等徽标。
- 画面里最好同时有：至少两个分组、一个展开态一个折叠态。

## 3. `screenshot-3.png` — 主题与字号设置

- 建议尺寸：900×900（方形，便于和上两张形成对比）。
- 拍什么：打开内嵌设置抽屉（工具栏齿轮或 ⋯ →「打开设置面板」），展示六组设置：字号与密度、配色主题、收录内容、过滤噪音、分组与子代理、视图与悬浮条。
- 画面里要能看清：字号倍率 1.5× 与「当前实际字号 ≈ 24px」提示、主题模式（跟随 DSH / 深色 / 浅色）、强调色色块。
- 如果一张放不下六组，优先保留「字号与密度」「配色主题」两组 + 抽屉标题。
